Entry for the [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty on make.fun.

## About

`main.ts` outputs a single-line resignation letter written in the voice of an overworked retry loop that was left running indefinitely after a temporary debug change.

## Run it

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (defaulting to `/output`) and writes `entry.txt` as UTF-8 text within the 140-character limit.
